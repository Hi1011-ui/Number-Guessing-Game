# Number Guessing Game

This is my first mini python project.

A simple Number Guessing Game built using Python.

In this game, the computer randomly selects a number between 1 and 100. The player has to guess the number, and the program provides hints after each guess.

The game also keeps track of the number of attempts taken to find the correct number.

## How It Works

1. The computer generates a random number between 1 and 100.
2. The player enters a guess.
3. The program compares the guess with the randomly generated number.
4. If the guess is higher than the number, the program asks the player to guess lower.
5. If the guess is lower than the number, the program asks the player to guess higher.
6. When the correct number is guessed, the game ends.
7. The total number of attempts is displayed.

## Technologies Used

* Python
* Random module
* While loop
* If-elif-else statements
* User input
* Variables and counters
